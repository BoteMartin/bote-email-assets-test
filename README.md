# bote-email-assets-test

Hébergement **temporaire** d'images d'emails pour le banc d'essai d'intégration BOTE (novembre 2026).
Uniquement pour des emails de test. À supprimer dès que l'hébergement définitif est en place :
`gh repo delete BoteMartin/bote-email-assets-test --yes`

Arborescence : `<client>/<année>/<UID>/<image>`
